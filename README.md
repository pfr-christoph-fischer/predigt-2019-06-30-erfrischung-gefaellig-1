# Erfrischung gefällig?

Erfrischung, neue Kraft, neues Leben für alle, die sich mühen. Für alle, die nichts haben. Für die, die bisher anderen Angeboten hinterhergerannt sind und dabei immer wieder auch auf die Nase fallen. Das verspricht Gott in Jesus Christus. Ein echtes Sonderangebot!<em> [Variante 2 dieser Predigt zum Taufgottesdienst am 2. Sonntag nach Trinitatis]</em>
